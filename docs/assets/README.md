# README-Bilder

- `yamikun-banner.png`: mit dem integrierten Imagegen-Tool erzeugtes README-Banner;
  `webassets/YamiKun.webp` diente als Referenz für das bestehende Maskottchen.

  fiktiven Beispieldaten statt Daten aus einer echten Datenbank.

```text
Use case: stylized-concept
Asset type: wide GitHub README banner, landscape 3:1 composition.
Primary request: Create a beautiful polished editorial banner for the Yamikun Discord community bot, using the supplied avatar as a character reference.
Input image 1: reference image for the existing Yami mascot's identity: messy black hair, violet eyes, black high collar and a small silver dangling cross earring, violet spectral flame.
Scene/backdrop: midnight-black to deep indigo atmosphere, refined soft violet embers; subtle silhouettes of collectible cards and a distant fantasy watchtower, kept subordinate.
Subject: preserve the recognizable illustrated anime mascot from the reference, chest-up on the right. The left side contains generous breathing space for the title.
Style/medium: detailed anime illustration with a clean premium gaming-community identity, restrained purple glow and crisp silhouette, high finish.
Text (verbatim): "YAMIKUN" in large refined bold white sans-serif on the left. Below in smaller widely spaced text: "DEIN TURM. DEINE REGELN."
Constraints: readable accurate typography, no additional text, no third-party logos, no UI mockups, no watermark. Keep all important elements inset from edges; landscape banner aspect ratio around 3:1.
```
